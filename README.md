# 金贝贝生图扩展插件 1.7

浏览器端图片生成工具。通过 OpenAI 兼容中转站（OpenAI-Compatible Endpoint）在本地浏览器中生成并下载图片。所有请求均从浏览器直接发起，密钥仅保存在本地（localStorage），服务端不存储。

## 功能

- 文本生成图片（文生图）
- 图片编辑 / 变体
- 可切换主题与外观（明 / 暗 / 跟随系统）
- 完全运行在浏览器中，无需后端

## 使用

1. 打开 `金贝贝生图扩展插件-1.7.html`（或下方部署地址）。
2. 在设置中填入你的 OpenAI 兼容接口地址与 API Key。
3. 输入提示词并生成。

## 部署

本项目是单文件静态页面，已通过 GitHub Pages 发布：

https://1634594707.github.io/jinbeibei-image-studio/

也可将 `金贝贝生图扩展插件-1.7.html` 下载到本地，双击直接用浏览器打开。

## 说明

- 页面通过 `cdn.jsdelivr.net` 加载 three.js（用于预览相关功能）。
- 接口地址、密钥均由使用者自行配置，工具本身不提供任何模型服务。
